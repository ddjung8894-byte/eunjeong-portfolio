02 / BACKGROUND & USER INSIGHT

여행 첫날의 정리는,
돌아오는 날까지 유지되지 않았습니다.

일반 파우치로 옷과 속옷을 나누니 짐을 찾기 쉬웠습니다. 하지만 옷의 부피는 여전히 컸고, 여행이 진행되자 입은 옷과 남은 옷이 섞였습니다.

01 / 부피

캐리어를 채우는 의류

옷은 생각보다 부피를 많이 차지했습니다. 의류 공간을 더 효율적으로 쓰는 기능이 필요했습니다.

02 / 분류

자주 쓰는 두 가지

옷과 속옷·양말 정도만 나눠도 찾기가 편했습니다. 분류 개수보다 실제 사용 빈도가 중요했습니다.

03 / 여행 중 변화

CLEAN에서 WORN으로

입은 옷이 늘어날수록 짐의 상태가 달라집니다. 귀국 때 다시 분류하는 불편이 생겼습니다.

04 / 작은 물건

작은 주머니의 효용

속옷 파우치 안의 작은 주머니에 면봉·화장솜·미니 세면도구를 따로 넣는 방식이 유용했습니다.

기획자의 개인 여행 경험입니다. 사용자 설문이나 다수 고객의 검증 결과로 일반화하지 않았습니다.

많이 나누는 대신, 실제로 많이 쓰는 두 가지에 집중

의류와 속옷·양말에 필요한 기능을 모으고, 여행 중 바뀌는 짐의 상태까지 정리할 수 있도록 기획했습니다.

PRIMARY TARGET · 기획 가설

2~5박 국내·해외여행을 즐기는
20~40대 1~2인 여행객

캐리어 공간은 아끼고 싶지만 많은 파우치를 챙기기는 번거로운 사람. 숙소에서 필요한 옷을 빠르게 찾고, 입은 옷과 작은 생활용품을 따로 정리하고 싶은 여행객을 가정했습니다.

PRODUCT 01 / CLOTHES COMPRESSOR

의류용 압축 파우치

의류를 위한 큰 수납공간에 압축 지퍼, CLEAN / WORN 분리 수납, 손잡이와 구분 표식을 제안합니다.

분리 구획의 위치·용량 배분·압축 시 간섭은 샘플로 검증할 항목입니다. 냄새나 수분 차단 기능을 의미하지 않습니다.

PRODUCT 02 / INNER ORGANIZER

속옷·양말 + 작은 생활용품

속옷과 양말 공간을 나누고 메시 포켓 2~3개에 작은 소지품을 모으는 구성입니다.

면봉·화장솜·미니 세면도구·여행용 화장품·상비약 수납을 가정합니다. 액체 누수 차단이나 의약품 보관 성능을 보장하지 않습니다.

CLEAN / WORN · 짐의 상태가 바뀌는 흐름

01 · 출발 전

깨끗한 옷을 CLEAN에 넣고 압축 지퍼로 정리

02 · 여행 중

입은 옷은 WORN으로, 남은 옷은 CLEAN에 유지

03 · 돌아온 뒤

WORN 공간의 빨랫감을 꺼내 세탁바구니로 이동

사용 시나리오 제안입니다. 압축 성능·내구성·실제 수납량 테스트 전입니다.

돌아오는 날까지

    입은 옷과 남은 옷은 따로.

    작은 물건도 흩어지지 않게.

    속옷·양말 공간과 메시 포켓의 역할을 구분합니다.

    2박3일 / 4박5일 정리 시나리오.

    짧은 여행은 분류 편의, 긴 여행은 늘어나는 WORN 공간 사용을 설명합니다. 의류 개수는 단정하지 않습니다.

  8. RETURN JOURNEY

    여행 정리는 집에 돌아올 때까지.

    WORN 공간의 빨랫감을 세탁바구니로 옮기는 장면으로 마무리합니다.

적립금 규모·운영 조건은 출시 전 결정합니다. 혜택 제공 사실은 리뷰에 안내하도록 설계합니다.

07 / AI-ASSISTED WORKFLOW

초안을 빠르게 만들고,
근거를 확인해 남길 문구를 결정합니다.

AI는 정보를 정리하고 문장을 제안하는 도구입니다. 상품 구성의 판단과 최종 표현의 책임은 기획자가 맡습니다.

  1. STEP 01Market Research

    공식몰의 가격·구성·판매 메시지 확인

  2. STEP 02AI Analysis

    경쟁구조와 제품 특징 비교 초안 정리

  3. STEP 03Human Decision

    여행 경험을 기준으로 구성·판매포인트 판단

  4. STEP 04AI Draft

    상품명·상세페이지·FAQ·SNS·광고 카피 초안

  5. STEP 05Human QA

    수치 근거·소재 정보·과장표현 확인과 수정

FINAL CONTENT

초안 / 사용하지 않음

검수 후 / 컨셉 카피

압축 지퍼를 이용해

02 · 소재와 방수 성능 주장 삭제

초안 / 사용하지 않음

판정: 문장 삭제. 소재와 방수 등급이 미정이므로 근거가 없습니다.

최종 처리

방수·젖은 옷 보관 문구 미사용

입은 옷과 남은 옷을 나누는 구조만 설명합니다. CLEAN / WORN 분리는 방수·방취 성능을 뜻하지 않습니다.
