# 최은정 · 이커머스 운영 포트폴리오

온라인 MD·AMD·이커머스 운영 실무와 두 개의 개인 MD 컨셉 프로젝트를 소개합니다.

여행용 압축파우치 카테고리 기획과 헤어케어 기획세트 프로젝트를 우선 소개하고, 실제 상업 작업·운영 경험·경력·AI 활용 사례를 구분합니다. 개인 컨셉 프로젝트는 실제 매출이나 전환율 성과를 제시하지 않습니다. 두 MD 프로젝트는 HTML 표·카드·직접 작성한 SVG 도형으로 구현한 네이티브 케이스스터디입니다. 가격대는 검증할 가설이며 KPI는 운영 시 확인할 지표입니다. AI 생성 인포그래픽이나 가짜 제품 사진을 사용하지 않습니다.

포트폴리오 소개 이미지의 건강 수치, 금액, 날짜, 일정과 입력 내용은 예시 문구로 대체했습니다.

GitHub Pages에서 `main` 브랜치의 루트를 게시합니다. 웹사이트 파일과 해당 화면에서 사용하는 이미지만 포함합니다.
