# 최은정 · 이커머스 운영 포트폴리오

온라인 MD·AMD·이커머스 운영 실무와 PACKBACK 개인 컨셉 프로젝트를 소개합니다.

PACKBACK은 제조·판매 전 상품 기획안입니다. 시장조사 출처, 가격 가설, 상품 구조, 판매 콘텐츠, 프로모션과 AI 검수 예시를 구분해 표시합니다. 실제 매출이나 전환율 성과를 제시하지 않습니다.

포트폴리오 소개 이미지의 건강 수치, 금액, 날짜, 일정과 입력 내용은 예시 문구로 대체했습니다.

GitHub Pages에서 `main` 브랜치의 루트를 게시합니다. 웹사이트 파일과 해당 화면에서 사용하는 이미지만 포함합니다.
